KGP ERP LOGIN HELPER · v1.3.1

Connect your Chrome profile’s Gmail.

The extension will request an ERP OTP, read the fresh code from your profile’s Gmail, and submit the ERP login once. Your ERP account must already send OTP emails to that same address. Installing an extension does not grant mailbox access by itself.

One-time Google setup

  1. In Google Cloud Console, choose your project and enable the Gmail API.
  2. Configure Google Auth Platform → Branding / Audience / Data Access. For personal testing, add your Chrome profile Google account as a test user. Add the scope https://www.googleapis.com/auth/gmail.readonly. Workspace administrators may restrict this permission.
  3. Under Google Auth Platform → Clients → Create client, select Chrome Extension. Enter the extension ID shown above in Item ID. A Web application or Desktop application client will not work here.
  4. Copy the generated client ID (ending in .apps.googleusercontent.com). No client secret is needed.
  5. In Terminal, from the extension folder, run:
    python3 configure-oauth.py YOUR_CLIENT_ID.apps.googleusercontent.com
    Alternatively, add the configuration below to manifest.json, replacing the client ID:
    "oauth2": {
  "client_id": "YOUR_CLIENT_ID.apps.googleusercontent.com",
  "scopes": ["https://www.googleapis.com/auth/gmail.readonly"]
}
  6. At chrome://extensions, reload KGP ERP Login Helper. Reload the ERP tab too. Keep this folder in its current location so its unpacked extension ID stays the same.
  7. Open the extension, unlock your vault, choose Connect this profile’s Gmail, and complete Google’s authorization. Verify that Chrome profile and Connected OTP mailbox show the same email.
  8. Enable Automatically request OTP & log in, then open/reload ERP. After the OTP request starts, polling continues if you switch tabs.

What happens to your email?

Google’s read-only Gmail scope permits reading mailbox contents; Google does not offer a scope limited to ERP OTP emails. This extension only searches recent OTP messages from erpkgp@adm.iitkgp.ac.in, reads matching message bodies locally, and sends only the extracted code to the ERP login page. It does not mark emails read, delete emails, send mail, or store message bodies. Chrome manages OAuth tokens; the extension does not save tokens to its own storage.

The mailbox must match the primary Google account signed into this Chrome profile. Another Google account signed into a Gmail tab is not sufficient. Non-Google mailboxes and signed-out Chrome profiles use manual OTP login.

Use Stop automatic login on ERP, turn off the setting, lock the vault, or disconnect Gmail to stop automation. An OTP already sent remains in your mailbox. If a request fails or two minutes pass, complete login manually or reload ERP for a deliberate new attempt.

For an external Google OAuth app in testing, Gmail authorization may expire after seven days; reconnect when prompted. Public distribution may require Google’s restricted-scope verification. This build has automated tests; live Gmail authorization and full account login still require your client setup.
